01 — The Question

What is the cheapest network that still works after any one cable fails?

Input
n sites and a cost for every possible cable between them.
Valid
Every site connected, and no bridge: no single cable whose loss splits the network (2-edge-connected).
Goal
Minimize total cable cost.
Why
Campus & ISP backbones, data centers, power grids. Availability is a security goal.

04 — Method · Brute Force Nick

Check every subset of links.

  • Examines every subset of the possible links (a bitmask over all E links).
  • Evaluates each subset with isFaultTolerant: remove each link in turn and check the rest stays connected. Keep the cheapest that passes.
  • Optimal? Yes. Every subset is checked (it skips only subsets with fewer than V links or that already cost more than the best found).
  • Time TBD: confirm with Nick
// src/brute_force/fault_tolerant_BF.cpp, lines 176–211 (verbatim)
for (int mask = 0; mask < (1 << E); mask++)
{
    vector<int> selected;

    count = 0;
    totalWeight = 0;

    // Build current subset
    for (int i = 0; i < E; i++)
    {
        if (mask & (1 << i))
        {
            selected.push_back(i);
            count++;
            totalWeight += edges[i].weight;
        }
    }

    // A 2-edge-connected graph must have
    // at least V edges
    if (count < V)
        continue;

    // Skip candidates that cannot improve
    // the current best solution (assuming
    // nonnegative edge weights)
    if (totalWeight >= minWeight)
        continue;

    // Check fault tolerance
    if (isFaultTolerant(V, edges, selected))
    {
        minWeight = totalWeight;
        bestFTMST = selected;
    }
}

05 — Method · Genetic Algorithm Neel Planned design from README; code not written yet

Evolve networks toward cheap and survivable.

  • Chromosome One bit per possible link (1 = built).
  • Fitness cost + penalty × (bridges + extra components). Lower is better.
  • Evolution Tournament selection → uniform crossover → bit-flip mutation (≈1/m), with elitism.
  • Stops after a fixed number of generations, or once the best cost stops improving.

06 — Method · Greedy Build-and-Repair Cristin

Build the cheapest tree, then patch its weak spots.

  1. Build a Minimum Spanning Tree with Kruskal's algorithm [5]. Every tree link is a bridge.
  2. Repair by adding the link with the lowest cost ÷ bridges newly covered.
  3. Repeat until no bridge remains.
  • Optimal? No. It never reconsiders a choice. Fast and deterministic.
